# 가계부

월급날 기준으로 한 달을 보는 개인 가계부예요. 설치 없이 브라우저에서 바로 씁니다.

## 기록은 어디에 저장되나요?

- 기록은 **쓰는 사람의 기기 브라우저 안에만** 저장되고, 어디로도 보내지지 않아요.
- 같은 링크를 여러 사람이 써도 각자 자기 기록만 보여요.
- 브라우저 데이터를 지우거나 기기를 바꾸면 기록이 사라져요. **설정 → 전체 백업 파일 받기**로 가끔 백업해 두고, 새 기기에서는 **백업 파일 불러오기**로 옮기세요.

## 휴대폰 홈 화면에 두기

- 안드로이드(크롬·삼성 인터넷): 메뉴 → 홈 화면에 추가
- 아이폰(사파리): 공유 버튼 → 홈 화면에 추가

## 처음 쓸 때

1. 오른쪽 위 톱니바퀴 → 가계부 시작일(월급날)과 통장을 정해요.
2. 고정 탭에서 매달 나가는 돈을 등록해요.
3. 쓴 돈은 오른쪽 아래 **+ 기록**으로 적어요.
